SOLMARA — Neon Streets: an original open-world crime game in the browser. Drive and walk a neon-lit city, steal cars, dodge the Solmara PD's wanted system, and run three chained story missions for the fixer Mara Quinn. Built with three.js, static files only, no network requests, synthesised WebAudio sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to walk/drive, mouse to look/aim, E to enter or exit a car, Space for handbrake/fire, Shift to run/boost, P to pause, M to mute, R to restart.
